# Full-Stack / Rust Engineer

Ես նախագծում և կառուցում եմ production ծրագրային համակարգեր, developer tools, backend հարթակներ և ծրագրային արտադրանքներ՝ կենտրոնանալով ճարտարապետության, հուսալիության և գործնական ինժեներական լուծումների վրա։

`Rust` · `Python` · `TypeScript` · `Next.js` · `Flutter`  
`Backend` · `Distributed Systems` · `Desktop` · `Cryptography` · `AI Engineering`

## Ինչով եմ զբաղվում

Ես աշխատում եմ ծրագրային ապահովման մշակման ամբողջ lifecycle-ի հետ՝ պահանջներից և համակարգային ճարտարապետությունից մինչև իրականացում, թեստավորում, deployment և համակարգի երկարաժամկետ զարգացում։

Իմ հիմնական ուղղություններն են՝

- Backend և API ճարտարապետություն
- Rust և համակարգային ծրագրավորում
- Full-stack արտադրանքի մշակում
- Բաշխված և event-driven համակարգեր
- Desktop հավելվածներ և developer tools
- Անվտանգություն և կրիպտոգրաֆիա
- AI-assisted development և AI agent infrastructure

## Հիմա ուսումնասիրում եմ

Ես ուսումնասիրում և կառուցում եմ AI-ի միջոցով ծրագրային մշակման նոր մոտեցումներ, այդ թվում՝ իմ սեփական AI agent միջավայրը՝ ոգեշնչված Hermes-ի նման գործիքներից, կենտրոնանալով developer workflows-ի, տեղային կատարման, ընդլայնելիության և ինժեներական վերահսկողության վրա։

Սա իմ աշխատանքի ուղղություններից մեկն է, ոչ թե ամբողջ գործունեության միակ կենտրոնը։

## Ինժեներական մոտեցում

Ինձ համար ավելի կարևոր է լուծել իրական ինժեներական խնդիրը, քան մեխանիկորեն կիրառել տեխնոլոգիաներ, pattern-ներ կամ ճարտարապետական կանոններ։

Իմ առաջնահերթություններն են՝

- հստակ ճարտարապետություն և սահմաններ;
- սպասարկելի համակարգեր;
- հստակ trade-offs;
- հուսալիություն և observability;
- security-conscious design;
- ուժեղ թեստավորում և verification;
- ավելորդ բարդության նվազեցում։
